## 7. 每个版本固定准出清单（DoD）

1. 根 `package.json` 升版本号（补丁版 `0.7.4/0.7.5`；功能版 `0.8.0`），子包不动。
2. `npm run verify` **exit 0**，记录逐道实测数字；道数变化在 RELEASES 里留痕。
3. 新增/修改的断言先做**证伪验证**：在错误输入上确认会红；前提不成立记 `skipped` 而非绿。
4. 门禁报红先问「是我造成的，还是环境造成的」——本项目已有两次判据假红记录（保活定时器不退出、非 key 窗口交通灯是灰的）。
5. `docs/RELEASES.md` 追加条目、`docs/devlog/` 留证据；未复跑 / 待人工项如实登记，不写「已验证」。
6. 打包 `--publish never`；发布前确认 token 可用、`publish.owner` 拼写、`latest-mac.yml` 的 url 与资产名一致；装 .app 用 `ditto`。
7. 真机项：解锁后跑 `verify:installed` + `verify:traffic-lights`；手工项（双击手感、拖窗、合盖唤醒）单列，不冒充自动通过。
