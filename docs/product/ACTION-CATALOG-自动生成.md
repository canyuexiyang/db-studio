## 键位裁定记录（报告 §4.2 的落点）

### 保存修改…（`save`）

- 键位：`⌘S`
- 裁定：⌘S 归「保存表修改」。SQL 标签下必须给出明确反馈（打开保存片段对话框），不能静默无响应

### 导出数据…（`export`）

- 键位：`⇧⌘E`
- 裁定：⇧⌘E 唯归导出。SQL 的 EXPLAIN 与网格的表达式模式必须让位

### 刷新表结构（`refresh-schema`）

- 键位：`⇧⌘R`
- 🔴 裁定：原为 ⌘R，与 SQL「执行全部」同键，而菜单层会先拦截 ⇒ SQL 侧永远收不到。刷新结构是低频动作，让位给 SQL 执行并改用 macOS「重新加载」惯例键 ⇧⌘R

### 重置字体（`font-zoom-reset`）

- 键位：`⌘0`
- 🔴 裁定：⌘0 唯归「重置字体」。网格「设为 NULL」让位到 ⌥0（数据动作不该被外观动作吃掉）

### 执行全部（`sql-run-all`）

- 键位：`⌘R`
- 🔴 裁定：⌘R 归 SQL 执行全部（会话内最高频）；刷新表结构让位到 ⇧⌘R。原方案是「菜单刷新结构 + 局部执行全部」，菜单层先拦截 ⇒ SQL 侧实际按不动

### 执行选中（无选区 = 当前语句）（`sql-run-selection`）

- 键位：`⌘⏎`
- 裁定：原 ⇧⌘R 让位给刷新结构；改用行业惯例 ⌘⏎（DataGrip / VS Code 同键）

### 执行计划（EXPLAIN）（`sql-explain`）

- 键位：`⇧⌘X`
- 裁定：⇧⌘E 已被「导出数据」占用，EXPLAIN 改用 ⇧⌘X（X = eXplain）

### 格式化 SQL（`sql-format`）

- 键位：`⌘I`
- 报告 §4.2：当前实现就是 ⌘I，不是 ⇧⌘F —— 以代码事实为准，不按印象列冲突

### 设为 NULL（`grid-set-null`）

- 键位：`⌥0`
- 🔴 裁定：原 ⌘0 与「重置字体」同键且被菜单层吃掉 ⇒ 改为 ⌥0

### 切换 SQL 表达式模式（`grid-expr-mode`）

- 键位：`⌘E`
- 🔴 裁定：原 ⇧⌘E 与「导出数据」同键且被菜单吃掉 ⇒ 编辑态改 ⌘E

### 查找本页（本地）（`grid-search`）

- 键位：`⌘F`
- 范围明确为「本页已加载行」，不是服务端检索

### 设计表…（`tree-design-table`）

- 键位：`F2`
- 报告 §4.2：F2 旧文案写「重命名」，实际行为是**进入表设计器**（不是树内改名）。文案已按真实行为统一为「设计表…」
