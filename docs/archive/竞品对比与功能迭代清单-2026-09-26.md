## 三、v1.1 建议短名单(按性价比排序)

1. **B1 片段保存 UI** — 半成品补齐,几乎零成本
2. **A2+A3 设 NULL + 单元格右键菜单** — 保真三件套的交互补全
3. **A1 结果集内查找(⌘F)** — 网格最高频缺失交互
4. **C3 树右键复制 DDL / 生成 INSERT** — 小成本高频
