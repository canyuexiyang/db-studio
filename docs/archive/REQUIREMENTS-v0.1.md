## 一、项目定位

一款运行于 macOS 的原生观感桌面应用，用于连接并管理多种数据库。功能上参考 Navicat，交互与视觉风格上参考 微信 / 微信小程序 / Apple 人机界面规范。

**核心原则**：单机自用、轻量、不依赖完整 Xcode 开发、先把一条链路做深再做宽。

---

## 二、技术选型

| 项目 | 选型 | 说明 |
|---|---|---|
| 应用框架 | **Electron + React + TypeScript** | 仅依赖 Node，不需要完整 Xcode 参与日常开发 |
| 构建工具 | Vite + electron-builder | dev 用 Vite HMR，打包用 electron-builder |
| 状态管理 | Zustand | 轻量，适合中等规模状态 |
| UI 层 | 自研组件 + CSS Variables | 不引入重型 UI 库，便于精确控制 Apple 风格 |
| SQL 编辑器 | CodeMirror 6 | 语法高亮、自动补全、选中执行 |
| 数据网格 | 自研虚拟滚动表格 | 十万行级流畅滚动 |
| 钥匙串 | keytar（或 safeStorage） | 密码存入 macOS 钥匙串 |
| Excel 导出 | exceljs | 支持 .xlsx 流式写入 |
| 数据库驱动 | mysql2 / ioredis / pg / mongodb | 各库官方 Node 驱动 |
| SSH 隧道 | ssh2 | 支持跳板机 |

**开发环境现状**：本机已有 Node v22.22.2、Xcode.app、VS Code。Rust 工具链未安装（本方案不需要）。

## 三、实施范围

### 3.1 第一阶段 MVP：MySQL 打样

先把以下链路完整跑通，验证交互手感：
连接管理 → 库表树 → 数据网格 → SQL 编辑器 → 导入导出。

跑通后再将抽象层横向复制到 Redis / PostgreSQL / MongoDB。

### 3.2 后续阶段

- 阶段二：PostgreSQL（schema、丰富类型、视图）
- 阶段三：Redis（KV 浏览、TTL、CLI）
- 阶段四：MongoDB（文档树、查询构造器、聚合管道）

### 3.3 明确排除（第一阶段不做）

- 数据同步 / 数据传输 / 定时备份调度
- 全局快捷键与命令面板（Cmd+K）
- 导入 Excel/CSV 到已有表
- ER 关系图
- 登录体系、团队协作、License、自动更新、崩溃上报

## 四、连接管理

| 功能 | 要求 |
|---|---|
| 基础直连 | 主机、端口、用户名、密码、默认数据库 |
| 连接测试 | 保存前一键测试连通性，返回耗时与版本信息 |
| SSH 隧道 | 支持跳板机：SSH 主机/端口/用户，密码或私钥认证 |
| SSL/TLS | 支持 CA 证书、客户端证书、密钥；可关闭证书校验 |
| 分组管理 | 自定义分组（开发/测试/生产等），支持嵌套、拖拽排序 |
| 颜色标签 | 分组或连接可指定颜色；生产环境建议红色警示 |
| 密码存储 | **密码存入 macOS 钥匙串**，本地配置文件只存非敏感信息 |
| 连接状态 | 显示已连接/未连接、连接耗时、服务端版本 |

## 五、界面结构

### 5.1 三栏经典布局

```
┌──────────┬──────────────────────────┬──────────────┐
│ 左侧栏   │ 中间工作区                │ 右侧详情栏   │
│ 连接树   │ 数据网格 / SQL 编辑器     │ 属性/结构    │
│ 库表树   │ （多标签）                │ （可折叠）   │
└──────────┴──────────────────────────┴──────────────┘
```

- 左侧：窄侧边栏（约 240px），图标化，类 Finder 侧边栏风格
- 中间：多标签工作区，每个表/查询一个标签
- 右侧：详情面板，宽约 280px，可折叠

### 5.2 MySQL 表详情分区

打开一张表后，中间工作区顶部为分区切换：

`数据` | `结构` | `索引` | `外键` | `DDL` | `查询`

### 5.3 视觉规范

| 项目 | 规范 |
|---|---|
| 外观模式 | 深色模式跟随系统，支持手动锁定浅色/深色 |
| 窗口观感 | 红黄绿交通灯按钮、毛玻璃材质侧边栏、圆角卡片 |
| 字体 | 中文苹方 / 英文 SF Pro 系；代码用等宽字体 |
| 圆角 | 卡片 8-10px，按钮 6px，输入框 6px |
| 配色 | 浅色：#FFFFFF / #F5F5F7 底；深色：#1E1E1E / #2C2C2E 底；主色蓝 #007AFF |
| 动效 | 120-200ms 缓动，克制使用 |
| 分隔线 | 极细 1px 半透明线，不用重阴影 |

### 5.4 安全交互

- `DROP` / `TRUNCATE` / 无 WHERE 的 `UPDATE` / `DELETE` → 强制二次确认弹窗
- 生产环境标签（红色）连接 → 危险操作再增加一层确认
- 网格就地编辑：改动单元格高亮标记，需显式点击「保存」才提交事务

## 六、MySQL 功能详述

### 6.1 SQL 编辑器

- 多标签页，每个标签独立会话
- 语法高亮（MySQL 方言）
- 自动补全：关键字、数据库名、表名、字段名
- **选中执行**：光标选中哪段执行哪段，未选中则执行全部
- 多条语句按分号拆解，逐条执行并分别返回结果
- **EXPLAIN 可视化**：一键查看执行计划，表格展示 type / possible_keys / rows / Extra
- 查询历史：记录执行过的语句，支持回填
- 常用片段收藏
- **SQL 美化/格式化**：一键格式化

### 6.2 数据网格

- 分页浏览，**默认打开表只加载 3000 条**（可配置，防止大表卡死）
- 就地编辑单元格，改动高亮，显式保存后提交
- 列头点击排序（ASC / DESC / 取消）
- 类 Excel 列筛选：等于、不等于、包含、大于、小于、为空、不为空
- **虚拟滚动**：十万行级流畅滚动
- 特殊字段友好展示：
  - 外键字段 → 显示关联表的可读值
  - `enum` / `set` → 下拉选择
  - `json` → 点击展开为格式化树
  - `text/blob` → 大文本弹窗编辑
  - 二进制 → 十六进制预览或导出为文件

### 6.3 表设计

- **可视化建表 / 改表**：图形化编辑字段名、类型、长度、小数点、非空、默认值、自增、注释
- 自动生成 DDL 预览，确认后执行
- **索引管理**：增删改索引，支持唯一索引、复合索引、索引类型与注释
- **只读查看 DDL**：`SHOW CREATE TABLE` 结果展示，支持复制
- 外键：查看与基础管理（ER 图不做）

### 6.4 导入导出

| 方向 | 格式 | 说明 |
|---|---|---|
| 导出 | **SQL** | 可选「仅结构 / 仅数据 / 结构+数据」；开关：DROP TABLE、IF NOT EXISTS、批量 INSERT 行数 |
| 导出 | **Excel (.xlsx)** | 整表或当前查询结果；大数据量分片写入 Sheet |
| 导出 | CSV | 可配分隔符、编码、是否含表头 |
| 导出 | JSON | 数组格式或 NDJSON |
| 导入 | **SQL 脚本** | 选择 .sql 文件执行，进度条 + 错误行定位 + 中途停止 |

导出对象：整表、选中行、当前查询过滤结果，三者可选。

## 七、各数据库能力矩阵（后续阶段）

### 7.1 Redis

- Key 树形浏览，按 `string / hash / list / set / zset` 类型分组
- 前缀搜索，使用 `SCAN` 增量扫描（禁用阻塞式 `KEYS`）
- 查看 / 编辑 / 删除 Key 值：hash 表格化、list 逐行、string 大文本
- JSON 值格式化查看
- TTL 查看与设置，可移除过期时间
- 命令行控制台（类 redis-cli）

### 7.2 PostgreSQL

- 与 MySQL 功能基本对齐（树 / 网格 / SQL 编辑器 / 导入导出）
- 树中多一层 **schema 节点**，支持 schema 切换、创建、删除
- 支持丰富字段类型：`array`、`jsonb`、`enum`、`uuid`、`interval` 等在网格中的专门展示与编辑
- 支持 **视图** 与 **物化视图**，树中单独节点，可查看定义与数据

### 7.3 MongoDB

- 集合浏览，文档以 JSON 树展开（支持嵌套对象与数组）
- 文档增删改，就地编辑；支持 `ObjectId`、`Date`、`Binary` 等特殊类型
- 查询构造器：图形化拼 filter / sort / project，或手写 JSON 查询
- 聚合管道编辑器
- 索引查看与管理

## 八、非功能需求

| 项目 | 要求 |
|---|---|
| 数据量 | 单表千万级以内，靠分页 + 虚拟滚动保证流畅 |
| 界面语言 | 简体中文 |
| 应用名称 | DB Studio（暂定） |
| 目标平台 | macOS（Apple Silicon 与 Intel 通用包） |
| 包体积预期 | 80-120MB（Electron 基线） |
| 长查询 | 可取消，需超时保护，避免界面假死 |
| 所有数据库操作 | 跑在 Electron 主进程，渲染进程通过 IPC 通信 |
