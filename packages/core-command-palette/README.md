# @dbstudio/core-command-palette

命令面板（D5 决策：提前到 v1）。

> 依据：PRD §6.8

## v1 三类能力

| 前缀 | 能力 |
|---|---|
| 无前缀 / `>` | 搜索表与视图 |
| `:` | 执行命令 |
| `@` | 搜索查询历史 |

**不在 v1 范围**：插件体系、自定义命令、搜索字段名、搜索单元格值、模糊命令别名。

前缀只认**首字符** —— 用户在表名里打 `@` 不该被当成搜历史。

## 打分（O(n)，无正则回溯）

性能要求：500 张表搜索，输入到结果更新 ≤ 50ms。所以命中即给分、不命中即跳过，
没有"尝试多种模式"的分支。

| 分档 | 场景 |
|---|---|
| 100 | 完全相等 |
| 80 | 前缀 |
| 60 | 连续子串 |
| 45 | 拼音首字母前缀 |
| 30 | 顺序子序列（`ord` 命中 `prod_order`） |
| 25 | 关键词命中（命令别名） |

再加：短标题加权（order 比 order_history_detail 更像用户想要的）、
最近使用衰减（半衰期 7 天）、使用次数（上限 +6）。

**输入为空时不做过滤** —— PRD 要求展示「最近打开的表」与「常用命令」，
所以空查询返回的是按最近使用排序的列表。

## 拼音

与 `core-tree-view` 同源口径（显式映射，不猜），避免"树里能搜到、面板里搜不到"。
